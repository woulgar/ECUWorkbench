# Third-party boundaries

Our authored code and skill are MIT licensed. We link to vendor documentation;
we do not bundle vendor firmware, manuals, INI/DBC definitions or private tunes.

Dependencies retain their upstream licenses. The installed Python MCP SDK is
the official `modelcontextprotocol/python-sdk` v1 line (MIT); XML parsing uses
`defusedxml` (PSF). `requirements.lock.txt` records the tested environment.

MSExtra license terms vary by firmware package and hardware. MaxxECU public
documentation/downloads are not evidence of an open firmware license. Speeduino
firmware GPLv2 and its official hardware CERN-OHL-S v2 are separate. rusEFI's
own license and existing MCP implementation remain upstream; no code is copied.

See [ecosystem sources](docs/ECOSYSTEM_RESEARCH.md) for exact references and
unverified version questions. Adapter availability is separate from permission
to distribute someone else's files.
